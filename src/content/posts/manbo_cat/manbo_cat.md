# 项目简介
- 我给这个机器猫取名“柠檬水”，后面都这样称呼它。
- 柠檬水可以实现的功能有：一些基础的运动（起立，前进，后退，左转，右转等）；一些简单的交互（打招呼，撒娇，让它唱歌等）；柠檬水是有体力值和开心值的，体力值不足时不会再动，只会接收睡觉的指令、

# 需要准备的硬件
- 1.3英寸oled,其他尺寸的也可以（4针）
- ASRPRO语音核心板（没有下载器也需要买一个）
- 180°舵机4个（SG90和mg90s都可以，后者贵一点质量好点）
- 锂电池（一般是航模用的那种）
- HC-SR04四脚的超声波传感器
- SS-12F44G5拨动开关
- type充电模块
- 喇叭
- 咪头（麦克风）
- STM32C8T6
