# 硬件准备（打算用什么去实现）
## 硬件清单
- 1.视觉传感器（重中之重）
    名称： USB 双目 OV9281 全局快门摄像头模组

    关键参数（必看）：

    接口： USB 3.0 (必须是 USB，否则插不上电脑)。

    传感器： OmniVision OV9281 (两颗)。

    快门方式： Global Shutter (全局快门) (必须有，否则高速运动会有果冻效应)。

    同步方式： 板载硬件同步 (双目图像必须同时曝光，不能有时间差)。

    基线 (Baseline)： 推荐 60mm 或 80mm (适合 0.5米-3米的测距范围)。

    帧率： 至少支持 1280x480 @ 60fps 或 100fps。

    单色/彩色： 黑白 (Monochrome) 推荐。黑白相机的感光度更好，处理速度更快，且更适合识别形状。

    用途： 充当机器人的眼睛，负责识别和测距。
- 2.辅助验证工具
    标定板： 购买一块 黑白棋盘格标定板 (或者自己用打印机打印在A4纸上，贴在硬纸板上，省钱)。

    测试物： 几个颜色鲜艳、大小一致的球（如橙色乒乓球）或标准纸团。
